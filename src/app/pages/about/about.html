ACERCA DEL PROYECTO

Entregas frecuentes, con confianza.

Este laboratorio muestra cómo automatizar el camino entre una actualización de código y una aplicación disponible en la web.

EL RECORRIDO

Un flujo. Tres momentos.

El pipeline se activa cuando se integra un cambio en la rama principal. Cada etapa prepara la siguiente y deja claro qué se está validando.

  1. 01

    Integración continua

    El repositorio recibe los cambios y ejecuta el flujo automatizado.

    GIT
  2. 02

    Pruebas y build

    Se comprueba la aplicación y se genera una versión lista para publicar.

    ANGULAR
  3. 03

    Despliegue y verificación

    GitHub Pages sirve la versión y una petición confirma que está en línea.

    PAGES

LO QUE PRACTICAMOS

Automatizar lo repetible.

Menos pasos manuales significa un proceso más fácil de repetir, revisar y mejorar. El laboratorio reúne herramientas reales en una aplicación pequeña y navegable.
